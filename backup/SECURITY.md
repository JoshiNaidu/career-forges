# Security Policy

## Supported Versions

CareerForge is currently under active development.

Security updates and patches are applied to the latest version of the project.

| Version | Supported |
| -------- | --------- |
| Latest   | ✅ |
| Older Versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

Please DO NOT create public GitHub issues for security vulnerabilities.

Instead, contact the project maintainer directly with:

- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fixes (if any)

We will investigate all legitimate reports and work on a fix as quickly as possible.

## Responsible Disclosure

We ask security researchers and contributors to:

- Avoid exploiting vulnerabilities publicly
- Avoid accessing user data without permission
- Give maintainers reasonable time to address issues before disclosure

## Security Best Practices

Users self-hosting CareerForge should:

- Keep dependencies updated
- Use environment variables for secrets
- Avoid exposing sensitive API keys publicly
- Deploy behind HTTPS in production
- Regularly update their deployment environment

## Scope

This policy applies to:

- Source code
- Official deployments
- Hosted services
- APIs maintained by the CareerForge project
